# NXP HoverGames Drone

Engineering documentation for a quadrotor based on the NXP RDDRONE-FMUK66 flight controller and PX4. The project covers hardware selection, electrical integration, flight physics and a staged bring-up plan.

## Repository guide

| Location | Contents |
|---|---|
| [docs/](docs/) | Architecture, hardware, PX4 setup, integration plan and references |
| [assets/](assets/) | Supporting diagrams and illustrations |

## Getting started

Start with [the system overview](docs/01_SYSTEM_OVERVIEW.md), then follow [the integration plan](docs/06_INTEGRATION_AND_TEST_PLAN.md). The first milestone is reliable RC-controlled flight; Raspberry Pi vision is a later development stage.

## Project context

This repository documents system design and integration. PX4 firmware is maintained separately in the linked autopilot repository.
